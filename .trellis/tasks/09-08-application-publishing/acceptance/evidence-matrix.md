## 规格审核补充（2026-09-24）

- **AC-PB1-SCHEMA**：合同已确认：`ShareNote`/`ShareNotebook` 使用可选 `ExpiresAt time.Time` / BSON `ExpiresAt`，秒级 UTC，缺失永久有效，不使用 TTL；实施和验收仍需证明索引 preflight、历史冲突和回滚语义。
- **AC-PB1-SCHEMA 索引补充**：`share_notes`/`share_notebooks` 各按个人与组分别有 `$type` partial unique `(UserId, resourceId, recipientId)` 和 recipient-leading 查询索引，strict/error JSON Schema validator 使个人/组字段互斥，`has_share_notes` 独立 `(UserId, ToUserId)` unique，仅作投影。Mongo 读回九项索引 keys/partial/unique 及 validator；故意制造同键重复、双/无 recipient、零值/`null`/错误类型及旧同名不兼容索引/validator，preflight 必须给出脱敏冲突数量且阻止就绪；手动核对修复后重新验证，不自动删改历史 grant。证据 `unrun`。
- **AC-PB3-CONTRACT**：合同已确认：`SetNote2Blog` raw boolean 仅全成功为 true，失败/未知/部分写入为 false；仍需验证真实逐项 receipt、资源归属和零伪成功投影。
- **AC-PB4-RECEIPT / AC-PB4-RECEIPT-GC**：独立 `(ActorId, SubmissionId)` 唯一 receipt；完整保留到 `max(TerminalAt, DeletedAt)+30 天`，只在 outbox 已 `sent/cancelled`（或不可重投的明确关闭 dead）且对账完成后由 publishing 每日最多 500 条 CAS 压缩并读回；pending/unknown/待重投/读回失败不可清理。永久保留最小身份/目标/摘要/结果引用及删除墓碑，不设 TTL；跨保留期重复请求与删除重试不重建/重发。核查扫描积压、索引数量/字节、容量失败不静默淘汰；全部运行证据 `unrun`。
- **AC-PB5-LIFECYCLE**：管理员与普通用户都可上传/自用，但自定义主题编辑、导出、删除和文件读写只能由 owner 执行；内置只读。非 active 删除要清理 metadata、文件树、静态入口；导出临时根和下载名 owner-scoped；`theme.json` 的 Name/Version/Author/AuthorUrl 类型错误返回可识别错误而不 panic，失败/未知不得遗留静态孤儿。
- **AC-PB4-NOTIFY/DELETE / AC-PB4-HANDOFF**：状态字段属于 outbox 元数据，覆盖 `unconfirmed/pending/retry/claimed/handoff_pending/handed_off/sent/cancelled/dead/handoff_unknown` 与非法迁移；取消赢 CAS 时任何领取快照不能发送，交接闸门赢时不能报已取消，闸门后崩溃/SMTP 结果不明不自动重发，已删除正文绝不补发。`TransportHandedOffAt` 是调用前保守闸门而非 SMTP 接受，须用真实 Mongo/SMTP 竞态及人工对账证据分别证明，旧账号/feedback outbox 不退化；实现和 admin 联验前 `unrun`/`delegated-unrun`。

已知风险（非安全验收通过项）：旧主题 HTML/JS 在原 URL/Host 渲染，文件置于程序的 `public/upload/` 中并不使上传者代码可信；同源访问时恶意脚本可能借登录访客权限请求主站，`theme.json` 描述值以 `raw` 插入管理页也可能造成注入。管理员公开/他人安装只控制可安装资格，不能将未公开文件当作自动私有；路径及 owner 越界必须按 AC-PB5 修复。Q-P7 选择兼容旧行为，**不提供跨用户脚本隔离保证，也不能把兼容回归视为安全验收通过**；风险须随交付证据移交，不再把隔离域和旧链接跳转列为验收项。

### 执行时证据记录模板

每个用例/矩阵行保留 commit、环境（Go/Mongo/browser/OS）、发现/运行/通过/失败/跳过数量、具体命令或 URL、首个错误及脱敏出处；没有环境应标 blocked/unrun 而不是 passed。服务单测先按每批 `-timeout 60s`，真实 Mongo/HTTP/浏览器按各自隔离的 owner gate 运行。Golden replay 只读；不把新生成物手工改为“预期结果”。
