# ADR-0001：以契约优先的依赖图推进技术栈现代化

- **状态**：Accepted
- **日期**：2026-08-25

## Context

Leanote 的 MongoDB 驱动、Web 框架和前端工具链都需要宽面迁移，但现有自动化回归不足，且 `/api/*` 与 USN 已被外部客户端使用。把所有升级放入一个分支会使回归无法归因，也无法独立回滚。

## Decision

先完成 HTTP Golden、USN 回归和可重复测试环境。基线完成后并行推进两条内部串行链：

```text
后端：Go 工具链 → Revel 1.1 → MongoDB 驱动 → 迁出 Revel
前端：构建链 → jQuery → Bootstrap → TinyMCE
```

CI/CD 等待两条链完成后汇合。根任务与 `frontend-libs` 是协调父任务，不直接承担生产代码改动。每个实现型任务独立规划、验证和归档；依赖同时写入任务文档和 `task.json.meta.depends_on`。

## Consequences

- 每个阶段都能用同一套契约基线定位行为变化并独立回滚。
- 前后端可以并行，单条链内仍保持明确的先后关系。
- 任务和文档数量增加，但每个评审单元更小且可独立验收。
- 父任务只有在所有子任务和跨链集成门禁完成后才能归档。
